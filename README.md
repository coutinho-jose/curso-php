# 🐘 PHP Course — Dani Krossing (YouTube)

Este repositório contém todos os meus exercícios, códigos de estudo desenvolvidos ao longo do **Curso de PHP** ministrado por **Dani Krossing** no YouTube.

O objetivo principal deste repositório é consolidar os meus conhecimentos em desenvolvimento web *backend*, boas práticas de programação e integração com bancos de dados.

---

## 📚 Conteúdos Abordados

O repositório está organizado de acordo com os módulos do curso:

- [x] **Sintaxe Fundamental:** Variáveis, tipos de dados e operadores.
- [x] **Estruturas de Controlo:** Condicionais (`if`, `switch`) e laços de repetição (`for`, `foreach`, `while`).
- [x] **Manipulação de Dados:** Modificação de *strings*, manipulação de *arrays* e funções pré-definidas.
- [x] **Funções e Escopo:** Definição de funções personalizadas e escopo de variáveis.
- [x] **Formulários e Requisições:** Processamento de dados via métodos `POST` e `GET`, além de tratamento de entradas de utilizadores.
- [x] **Gestão de Sessões e Cookies:** Criação de sessões, autenticação e boas práticas de segurança (ex: *hashing* de senhas).
- [x] **Integração com BDMG (MySQL/PDO):** Conexão segura a banco de dados usando **PDO**, manipulação de dados (*CRUD*) e prevenção contra *SQL Injection* com *Prepared Statements*.
- [x] **Programação Orientada a Objetos (OOP):** Classes, objetos, herança, encapsulamento e visibilidade (`public`, `protected`, `private`).

---
